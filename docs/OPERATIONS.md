# 运维手册（OPERATIONS）

面向日常运维、客服与实施，覆盖巡检、租户开通、品类上下线、消息队列、故障处理。

---

## 1. 服务与端口

```bash
systemctl status meiye-backend nginx
ss -lntp | grep -E '8081|80|443'
curl -s http://127.0.0.1:8081/api/health
```

| 服务 | 命令 |
| --- | --- |
| 后端 | `systemctl restart meiye-backend` |
| Nginx | `nginx -t && systemctl reload nginx` |
| MySQL | `systemctl status mysqld` |
| Redis | `redis-cli -h <host> -a <pwd> ping` |
| RabbitMQ | `rabbitmqctl status` |

日志：

```bash
journalctl -u meiye-backend -n 200 --no-pager
tail -f /opt/meiye/data/logs/meiye.log
tail -f /var/log/nginx/meiye-api.error.log
```

## 2. 日常巡检（建议每日）

1. `/api/health` 返回 `UP`，`database=UP`；
2. 后端错误日志无连续异常；
3. RabbitMQ 队列无堆积（`rabbitmqctl list_queues name messages consumers`）；
4. Redis 内存与命中率正常（`redis-cli info memory`）；
5. 备份任务成功，备份文件大小合理；
6. 审计日志中「越权拦截」是否异常增多；
7. 磁盘使用率 < 80%（`df -h`），日志已轮转。

`deploy/scripts/healthcheck.sh` 可用于自动巡检，非 0 退出码表示异常。

## 3. 租户运营

### 3.1 开通租户

平台管理端 → 租户管理 → 新增：

1. 填写租户编码（唯一、大写字母数字，如 `5MY`）、名称、联系人、到期时间；
2. 状态启用后，系统自动创建租户管理员账号与默认角色；
3. 在「品类插件库」为该租户开通业务品类（美容/医美/养生/美发/美甲等）；
4. 租户管理员登录后配置门店、工位、服务项目、技师、卡种、提成规则。

租户编码是登录与门户路由的关键字，**上线后不建议修改**。

### 3.2 停用/续费

- 停用租户：平台 → 租户管理 → 状态改为停用，该租户所有账号立即无法登录；
- 续费：修改到期时间；到期前系统通过消息模板发送提醒；
- 删除：逻辑删除，数据保留，可由 DBA 按合规要求物理清理。

### 3.3 品类插件上下线

平台 → 品类插件库：维护品类元数据（编码、名称、图标、默认菜单、表单 schema）。
租户 → 品类开关：启停具体品类。

拦截规则：

- 未启用品类：列表过滤、详情 403、下单/预约/收银全链路拒绝；
- 已启用后关闭：历史数据保留，仅禁止新增业务；
- 平台下钻租户时只读，不能代租户改配置。

详见 [BIZ-PLUGIN.md](./BIZ-PLUGIN.md)。

### 3.4 账号与权限

- 平台角色：`SYSTEM`（超管）、`OPERATOR`（运营）；
- 租户角色：`TENANT_ADMIN`、`STORE_MANAGER`、`CASHIER`、`MARKETING`、`FINANCE`、
  `TECHNICIAN`、`CUSTOMER`；
- 菜单与按钮权限由角色-菜单关联控制，菜单可在「菜单可视化」中调整排序、图标、显隐；
- 员工离职：停用账号而非删除，保留审计与业绩归属。

## 4. 业务日常操作

### 4.1 预约与排班

- 客户小程序/H5 预约 → 门店确认 → 技师接单 → 到店核销；
- 排班冲突由后端校验，重复时段返回业务错误；
- 爽约可在预约列表中标记，影响客户信用分（可配置）。

### 4.2 收银与核销

- 收银台支持现金、微信、支付宝、会员卡、储值、组合支付；
- 核销需订单号或核销码，重复核销被拒绝；
- 交接班：开班录入备用金，交班核对现金/线上金额，差异需备注。

### 4.3 会员卡与储值

- 卡种定义次数/储值/折扣/有效期；
- 充值赠送按活动规则生成赠送金额或次数；
- 退款需财务角色审批，产生负向流水，禁止直接改余额。

### 4.4 技师结算与提现

- 订单完成后按提成规则生成提成明细；
- 结算单按周期生成，支持平台/门店/技师多方分账；
- 提现申请 → 财务审核 → 打款 → 状态回写，全流程留痕。

### 4.5 营销与售后

- 优惠券、活动、积分、分销佣金均在营销模块配置；
- 售后（退款/返工/投诉）由店长审批，关联原订单；
- 回访任务按服务完成后自动生成。

## 5. 消息与微信

- 消息模板在「消息模板」维护，支持站内信、短信、微信模板消息（需资质）；
- 发送失败可在「发送日志」重试；
- 公众号回调地址：`https://api.example.com/api/public/wechat/{tenantCode}/callback`；
- 未配置资质时 `WECHAT_MOCK=true`，模板消息仅落库并打印模拟日志。

详见 [WECHAT.md](./WECHAT.md)。

## 6. 对象存储

支持 5 种驱动（本地 / MinIO / 阿里云 OSS / 腾讯云 COS / 七牛），在租户配置或平台参数中切换。
切换后历史文件 URL 仍指向原驱动，**不要删除旧驱动数据**。上传大小限制与允许类型由后端校验，
不依赖前端。

## 7. 缓存与队列

| 场景 | 说明 |
| --- | --- |
| 登录态 | JWT 无状态，Redis 仅存黑名单/限流计数 |
| 编号生成 | Redis 自增 + 数据库回查，保证租户内唯一 |
| 限流 | Redis 计数，按接口维度 |
| 防重 | `X-Request-Id` / `X-Idempotency-Key` + Redis 短时锁（重复返回 429） |
| 消息 | RabbitMQ 异步发送，失败重试并记录 |

清理缓存前确认影响面；**禁止直接 `FLUSHALL`**。

## 8. 故障处理

### 8.1 后端无法启动

```bash
journalctl -u meiye-backend -n 100 --no-pager
```

常见原因：环境变量缺失、数据库连不上、端口占用、`DATA_AES_KEY` 长度非法。

### 8.2 接口大面积 500

1. 查看日志首个异常堆栈；
2. 确认数据库连接池是否耗尽（Hikari 日志）；
3. 确认 Redis/RabbitMQ 是否可达；
4. 必要时回滚上一版本（见部署手册）。

### 8.3 登录失败

- 平台账号：不传租户编码；租户账号：需传租户编码；
- 客户/技师登录：`userType=CUSTOMER|TECHNICIAN`；
- 连续失败触发限流，等待 1 分钟或清理限流键。

### 8.4 数据不一致

- 余额/次数以流水为准，必要时由财务发起调账（生成流水，不直接改字段）；
- 订单状态机不允许跳步，异常订单由管理员走售后流程处理；
- 所有后台修改均写入审计日志，可按操作人/时间追溯。

## 9. 发布窗口与变更管理

- 常规发布建议 22:00–23:00，避开预约高峰；
- 发布前：备份数据库、确认回滚包、通知客服；
- 发布后：健康检查、登录冒烟、下单/核销冒烟、观察 30 分钟错误率；
- 数据库变更必须附回滚 SQL，禁止在业务高峰执行大表 DDL。
